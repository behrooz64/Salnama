# 🌿 سال‌نما | Salnama

برنامه‌ای ساده و کاربردی برای نمایش **حیوان سال بر اساس تقویم هجری شمسی**، همراه با نام فارسی و نام ترکمنی حیوان.

## ✨ هدف پروژه

سال‌نما برای این طراحی شده است که کاربر با انتخاب یک سال شمسی، حیوان متناظر آن سال را به‌صورت خودکار مشاهده کند.

برای مثال، با انتخاب سال **۱۴۰۹**، برنامه حیوان متناظر آن را به‌صورت خودکار نمایش می‌دهد.

## 🐾 امکانات

- انتخاب سال هجری شمسی
- محاسبه خودکار حیوان سال
- نمایش نام فارسی حیوان
- نمایش نام ترکمنی حیوان
- جدول چرخه ۱۲ ساله حیوانات
- رابط کاربری فارسی و راست‌چین
- طراحی مناسب برای موبایل و دسکتاپ
- قابلیت اجرا به‌صورت **PWA (Progressive Web App)**
- ساختار قابل توسعه برای امکانات آینده

## 🌐 فناوری

نسخه اولیه پروژه با فناوری‌های وب ساخته می‌شود تا روی مرورگر اجرا شود و در مرورگرهای سازگار امکان نصب به‌عنوان اپلیکیشن را نیز داشته باشد.

فناوری‌های اصلی:

- HTML5
- CSS3
- JavaScript
- PWA

## 📅 منطق سال‌ها

برنامه بر اساس چرخه ۱۲ ساله حیوانات کار می‌کند و با انتخاب سال هجری شمسی، حیوان متناظر را مشخص می‌کند.

اطلاعات حیوانات شامل نام فارسی و نام ترکمنی خواهد بود. نمونه:

| فارسی | ترکمنی |
|---|---|
| موش | سیچان |
| گاو | اوی |
| پلنگ | بارس |
| خرگوش | تویان |
| اژدها | اژدرها |
| مار | ییلان |
| اسب | آت |
| گوسفند | قویین |
| میمون | مییمون |
| مرغ | تووخ |
| سگ | ایت |
| خوک | دونگوز |

> نام‌های ترکمنی به‌صورت داده قابل ویرایش نگهداری می‌شوند تا در صورت نیاز بتوان شکل نوشتاری یا گویشی آن‌ها را اصلاح کرد.
