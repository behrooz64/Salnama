# 🌿 سال‌نما | Salnama

برنامه‌ای ساده و کاربردی برای نمایش **حیوان سال بر اساس چرخه سنتی ۱۲ حیوانی ترکمنی (Müçe)** با نام فارسی و نام ترکمنی.

## ✨ امکانات

- انتخاب سال هجری شمسی
- محاسبه خودکار حیوان سال بر اساس چرخه Müçe ترکمنی
- نمایش نام فارسی و ترکمنی
- جدول چرخه ۱۲ ساله
- انتخاب حیوان از جدول و رفتن به نزدیک‌ترین سال متناظر
- رابط کاربری فارسی و راست‌چین
- طراحی مناسب موبایل و دسکتاپ
- قابلیت اجرا به‌صورت PWA

## 🐾 چرخه Müçe

ترتیب مورد استفاده در نسخه فعلی:

| فارسی | ترکمنی | نماد |
|---|---|---|
| موش | syçan | 🐀 |
| گاو | sygyr | 🐂 |
| پلنگ | bars | 🐆 |
| خرگوش | towşan | 🐇 |
| ماهی | luw | 🐟 |
| مار | ýylan | 🐍 |
| اسب | ýylky | 🐎 |
| گوسفند | koý | 🐑 |
| میمون | bijin | 🐒 |
| مرغ | takyk | 🐓 |
| سگ | it | 🐕 |
| خوک | doňuz | 🐖 |

مبنای محاسبه نسخه فعلی **۱۴۰۱ = bars (پلنگ)** است؛ بنابراین **۱۴۰۹ = it (سگ)**.

> نکته: Müçe سنتی با چرخه رایج فارسی ۱۲ حیوانی یکسان نیست. در این پروژه، چرخه ترکمنی مبنای محاسبه است و نام‌ها با املای لاتین استاندارد ترکمنی نمایش داده می‌شوند.

## 📅 نکته درباره سال

در منابع مربوط به Müçe، آغاز سال حیوانی با نوروز و حدود ۲۱ مارس بیان می‌شود. این نسخه برای سادگی، حیوان را بر اساس **شماره سال هجری شمسی** محاسبه می‌کند.

## 🌐 فناوری

## 🚀 وضعیت

نسخه اولیه قابل استفاده است و منطق چرخه ترکمنی، جدول حیوانات، نام‌های ترکمنی و PWA پیاده‌سازی شده‌اند.
